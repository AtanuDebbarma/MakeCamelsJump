# Make Camels Jump

Yes, this mod does exactly what the name tells you. It makes camels jump.

Vanilla camels ignore the space bar. Horses do not. This fixes that.

Jump uses leftover vanilla camel clips, so it will never look as clean as a horse jump. That is a TaleWorlds leftover, not a bug in this mod.

**Download:** [Make Camels Jump on Nexus Mods][nexus] (link after upload)

## Compatibility

Works with vanilla camels and with camel mods that still use the normal camel (Camel Cavalry, Camel Armor BM168, Improved Camels, and similar). Load it after Native. A mod that replaces the camel entirely may conflict.

## Installation

1. Extract the `MakeCamelsJump` folder into `Mount & Blade II Bannerlord\Modules`.
2. Enable **Make Camels Jump** in the launcher and place it after Native.

## Uninstall

Turn the module off in the launcher, or delete the folder. Nothing is written to your save.
